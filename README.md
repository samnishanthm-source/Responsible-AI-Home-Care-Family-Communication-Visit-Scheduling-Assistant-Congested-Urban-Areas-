# Responsible AI Home-Care Family Communication & Visit Scheduling System

An end-to-end **synthetic-data** prototype that converts raw home-care scheduling/visit data into
role-appropriate, consent-aware, uncertainty-aware family communication summaries — with an explanation
layer, potential-harm detection, fallback/escalation workflow, and a measured baseline-vs-prototype
evaluation.

⚠️ **No real patient data is used anywhere in this project.** All data is generated by
`scripts/generate_data.py`.

## Quick Start

```bash
pip install -r requirements.txt

# 1. Generate synthetic data
python scripts/generate_data.py

# 2. Run the baseline-vs-prototype experiment (writes reports/evaluation_report.md)
python scripts/run_experiment.py

# 3. Run the synthetic stakeholder validation (writes reports/user_feedback.md)
python scripts/stakeholder_validation.py

# 4. Launch the application
streamlit run dashboard/streamlit_app.py
```

## Running Tests

```bash
pytest tests/ -v
```

If `pytest` isn't installed in your environment, the same tests can be run directly:

```bash
python - <<'EOF'
import glob, importlib.util
for path in sorted(glob.glob("tests/test_*.py")):
    spec = importlib.util.spec_from_file_location(path, path)
    mod = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(mod)
    for name in dir(mod):
        if name.startswith("test_"):
            getattr(mod, name)()
            print("PASS", path, name)
EOF
```

## What Makes This "Responsible AI" (not just a text generator)

1. **Consent + role enforcement** before any disclosure (`app/rules/pipeline.py::filter_fields`).
2. **Uncertainty banding** (High/Moderate/Low/Unknown) — never states a low-confidence ETA as fact.
3. **Potential harm scoring** (`probability x impact`) with Low/Medium/High/Critical classification.
4. **Fallback + human escalation** for conflicting data, missing ETA, or high risk — never guesses.
5. **Explanation layer** — every message ships with a human-readable "why" trail.
6. **Measured evaluation** — baseline vs prototype compared on 320 synthetic scenarios across 5 metrics,
   with honestly-reported results (including two sub-target metrics, analyzed in
   `reports/failure_analysis.md`) rather than fabricated numbers.

See `docs/responsible_ai.md` for the full Responsible AI design writeup and known limitations.
